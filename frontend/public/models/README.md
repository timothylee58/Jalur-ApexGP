# 3D models

Place a compressed glTF binary here as:

```
sepang.glb
```

Served at `/models/sepang.glb`. The landing "Orbit Sepang" stage auto-detects
it; until then it links to the procedural `/circuit` explorer.

Tips:
- Export glTF 2.0 from Blender (Y-up)
- Keep under ~8 MB; use Draco / gltf-transform if larger
- Original / licensed assets only — same standard as tourism copy
